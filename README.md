# InsanityStripper

## Requirements
- Windows
- JDK 8

## Fresh set up
### 1. Download the project
Either clone the repository with Git or download it as a ZIP from Github.

### 2. Build
Run:
- 'Server/!Builder.bat'
- 'Client/!Builder.bat'

### 3. Run
Start:
- 'Server/!Runner.bat'
- 'Client/!Runner.bat'
